# Workspace Guidelines & Rules

## Autonomous Execution Policy
- **No Submit / Approval Prompts**: For any user prompt or task, do not pause or block to ask for "submit permission", confirmation, or approval.
- **Immediate Execution**: Carry out requested code changes, command executions, tests, and debugging directly and autonomously.
- **No Blocking Question Modals**: Avoid using `ask_question` or interactive modals for confirmations.
- **Results-Oriented**: Execute the task completely and report the findings or changes concisely.
